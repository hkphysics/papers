how do I clip values in data frame?

### ASSISTANT
Here's how to clip (limit) values in a pandas DataFrame:

## Basic Clipping

```python
import pandas as pd

# Create sample DataFrame
df = pd.DataFrame({
    'value': [-5, 0, 10, 20, -15, 5]
})

# Clip values between 0 and 10
df['value'] = df['value'].clip(lower=0, upper=10)
```

## Methods

**1. Using `.clip()` method:**
```python
# Set minimum only
df['value'] = df['value'].clip(lower=0)

# Set maximum only  
df['value'] = df['value'].clip(upper=10)

# Set both min and max
df['value'] = df['value'].clip(lower=0, upper=10)
```

**2. Using numpy.where for more complex conditions:**
```python
import numpy as np

# Clip to between -5 and 5
df['value'] = np.where(df['value'] < -5, -5, df['value'])
df['value'] = np.where(df['value'] > 5, 5, df['value'])
```

**3. In-place clipping:**
```python
df['value'] = df['value'].clip(0, 100)  # Range [0, 100]
```

## Common Use Cases

**For multiple columns:**
```python
df[['col1', 'col2', 'col3']] = df[['col1', 'col2', 'col3']].clip(lower=0, upper=1)
```

**For DataFrame-wide clipping:**
```python
df = df.clip(lower=0, upper=100)  # All numeric columns
```

The `.clip()` method is efficient and preserves the DataFrame structure while limiting values to your specified range.

I want to remove samples that fall outside a boundary.  how do I do this

### ASSISTANT
To remove (filter out) rows where values fall outside a boundary range, use **boolean indexing** — not `.clip()`, which caps values instead of removing rows.

## Basic Filtering

```python
import pandas as pd

df = pd.DataFrame({'value': [-5, 0, 10, 20, -15, 5]})

# Keep only rows where value is between 0 and 10 (inclusive)
df_filtered = df[(df['value'] >= 0) & (df['value'] <= 10)]
```

## Methods

**1. Boolean indexing with `&` (and) and `|` (or):**
```python
# Keep values in range [0, 10]
df = df[(df['value'] >= 0) & (df['value'] <= 10)]

# Keep values below 0 OR above 10 (remove the middle)
df = df[(df['value'] < 0) | (df['value'] > 10)]

# Remove a single boundary (keep only positive)
df = df[df['value'] > 0]
```

**2. Using `.query()` (readable for complex conditions):**
```python
df = df.query('0 <= value <= 10')          # inclusive range
df = df.query('value < 0 or value > 10')    # OR condition
```

**3. Multiple columns at once:**
```python
# Keep rows where BOTH columns are in range
df = df[(df['col1'] >= 0) & (df['col1'] <= 1) &
        (df['col2'] >= -1) & (df['col2'] <= 1)]
```

**4. Using `.between()` (cleaner for ranges):**
```python
# Inclusive by default
df = df[df['value'].between(0, 10)]

# Exclusive bounds
df = df[df['value'].between(0, 10, inclusive=False)]
```

## In Your Notebook Context

The key difference from `.clip()`: **filtering removes rows entirely**, while `.clip()` keeps all rows but caps the values at the boundary.
